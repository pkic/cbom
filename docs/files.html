Files and how to run them

The machine-readable artifacts that constitute the example, together with the commands used to reproduce the conformance verdicts.

Artifacts

FileDescription
profile-interface-disclosure.mdProse profile specification (product-level and per-interface rules)
profile-interface-disclosure.rules.jsonMachine-readable rules, including the appliesTo version range
mapping-cyclonedx-spdx.mdComplete requirement-to-format mapping
cbom-pass.cyclonedx.jsonConforming example CBOM (CycloneDX 1.7)
cbom-fail.cyclonedx.jsonNon-conforming example; omits the management interface
validate_cbom.pyVersion-aware validator
versioning-and-legacy-cboms.mdTreatment of older CBOM files

Running the validator

# conforms (CycloneDX 1.7)
python validate_cbom.py cbom-pass.cyclonedx.json profile-interface-disclosure.rules.json

# does not conform; fails product rule P2 (no management interface)
python validate_cbom.py cbom-fail.cyclonedx.json profile-interface-disclosure.rules.json

# JSON output, for integration into a continuous-integration gate
python validate_cbom.py cbom-pass.cyclonedx.json profile-interface-disclosure.rules.json --json

Reproducing the version bands

# produce a legacy (1.6) and an unsupported (1.5) copy, then evaluate each
python - <<'PY'
import json
b = json.load(open("cbom-pass.cyclonedx.json"))
for v in ("1.6", "1.5"):
    b["specVersion"] = v
    json.dump(b, open(f"cbom-{v}.json", "w"))
PY
python validate_cbom.py cbom-1.6.json profile-interface-disclosure.rules.json   # legacy: accepted with a warning
python validate_cbom.py cbom-1.5.json profile-interface-disclosure.rules.json   # unsupported: refused
