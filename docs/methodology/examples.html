Example CBOMs

Section D.3 of annex D This page explains section D.3 of annex D, Tools and examples, of Applying the methodology, with diagrams, worked examples and checks you can run. The publication is the authoritative text: where the two differ, the publication applies. Download Publication 3 (Word)

Every example record the working group has written, grouped by the story it tells. Open a record to read it as a page: what the subject is, each cryptographic interface, how far each purpose has moved to post-quantum cryptography, and the validator's verdict for each profile.

There are two kinds of example. A record shows what a good answer looks like. A failure variant is a copy of a record with one thing broken, so that it fails exactly one rule. Each variant shows what was changed and how to fix it. Every verdict on this page is checked by the test suite.

✓ profile conforms ✕ profile does not conform gap analysis a real product described from public documentation, meant to show what is missing

The page data is generated by tools/build_examples_site.py from the test cases and the reference validator, validate_cbom.py; the test suite fails if it is out of date. The same examples are listed as a table in examples/README.md.
